# BuddyCheck setup

Generated by `buddycheck init` for **KilianJimenez/buddycheck** (provider: GitHub Copilot CLI, issue tracker: GitHub Issues).

Finish these steps once; after that the loop and the SDD workflows run on their own.

## 1. Repository secrets

Add these under **Settings → Secrets and variables → Actions → Repository secrets** of `KilianJimenez/buddycheck`:

- `COPILOT_CLI_TOKEN` — Copilot CLI authentication token. Run `copilot` locally, sign in, and copy the token it stores (or mint a token with Copilot access) — the workflows pass it to the Copilot CLI as its credential.
- `GH_PAT` — Classic personal access token with the `repo` and `workflow` scopes. Required because the default `GITHUB_TOKEN` is not allowed to push changes to workflow files, which the agents may need to do.

## 2. Repository settings

- Settings → Actions → General → Workflow permissions: select **Read and write permissions**.
- Settings → Actions → General → Workflow permissions: enable **Allow GitHub Actions to create and approve pull requests**.

## 3. Local CLI

- Install the Copilot CLI: `npm i -g @github/copilot`.
- Authenticate once locally: run `copilot` and follow the sign-in prompt.
- Verify with `copilot --version` before running `bash .buddy/buddy-once.sh`.

## 4. How to trigger it

**SDD workflows** — comment on an issue (or its comments); only comments authored by
`KilianJimenez` are honoured, everything else is ignored:

| Comment     | What it does                                                        |
| ----------- | ------------------------------------------------------------------- |
| `!grill`    | Grills the idea in the issue and shapes it into a spec.             |
| `!to-plan`  | Turns the grilled spec into a plan plus suggested issue slices.     |
| `!to-issues`| Creates the slice issues from the plan.                             |

**Agent loop**

- On GitHub: Actions → **Buddy - Once** → *Run workflow* (`workflow_dispatch`).
- Locally: `bash .buddy/buddy-once.sh` — picks an issue labelled `ready-for-agent`,
  runs the coder agent, then the oracle review, and opens a pull request.
